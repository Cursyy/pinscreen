# pinscreen

Plug in a monitor, pick a side. pinscreen is a tiny macOS menu bar app that asks where your new external display sits (left, right, top, bottom) the moment you connect it, and applies the layout in one click.

## Requirements

- macOS 13 or later
- One Mac display plus one external monitor

## Build from source

1. Clone the repo and open `pinscreen.xcodeproj` in Xcode 15 or later.
2. Select the PinScreen scheme and run.
